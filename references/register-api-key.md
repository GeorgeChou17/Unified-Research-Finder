# 小白指南：注册 NCBI 账户并获取免费的 PubMed API Key

> 这个技能**不申请 key 也能用**。只有当你需要"一次查很多篇"或"查得快一点"时，才需要做下面这一步。
> 全程免费，不用绑卡、不用付费，5 分钟左右搞定。

## 一、先确认：你到底需不需要？

| 你的使用场景 | 需要申请吗 |
|------|------|
| 平时每次查几篇文献（≤20 篇） | 不需要，直接能用 |
| 想一次抓取几十上百篇、或写批量脚本 | 需要，能明显提速 |
| 搜索时偶尔报错"访问太频繁" | 需要，能避免被限流 |

## 二、第一步：注册一个 NCBI 账户（没有就先注册）

1. 打开网站：<https://account.ncbi.nlm.nih.gov/signup/>
2. 点 **Register for an NCBI account**（注册账户）。
3. 可以用**邮箱**注册，也可以直接用 **Google / Microsoft 账号**一键登录（最省事）。
4. 按提示填邮箱、设密码，收一封验证邮件点链接确认。
5. 注册完成，记住这个账号即可。

> 小提示：NCBI 是"美国国立生物技术信息中心"，PubMed 就是它家的数据库。注册它家账户不会给你发广告。

## 三、第二步：生成一个 API Key（一次性操作）

1. 登录后打开：<https://www.ncbi.nlm.nih.gov/account/settings/>
2. 找到 **API Key** 这一栏，点 **Create an API Key**（创建密钥）。
3. 系统会给你一串类似这样的字符（举例）：
   ```
   0123456789abcdef0123456789abcdef0123
   ```
4. **复制保存好这串字符**（建议先贴在记事本里，后面用得到）。

> 这就是你的"API Key"。它相当于你的专属通行码，能让你查文献的速度从每秒 3 次提升到每秒 10 次。

## 四、第三步：把这个 Key 告诉本技能（两种方式任选）

### 方式 A：临时用一次（在对话里说）
直接在对话里告诉我：
> "用邮箱 me@example.com 和 API key 0123...ef 帮我查 XX"

我会把它作为本次命令的参数传给脚本（`--email` 和 `--api-key`）。

### 方式 B：设成环境变量（一劳永逸，推荐）
把 key 存到电脑的环境变量里，以后不用每次都说：

- **Windows（PowerShell）**：
  ```powershell
  [System.Environment]::SetEnvironmentVariable("NCBI_API_KEY", "0123...ef", "User")
  ```
  设置后**重启一下 WorkBuddy** 让它读到新变量。
- **macOS / Linux**：把下面这行加到 `~/.zshrc` 或 `~/.bashrc`，然后重开终端：
  ```bash
  export NCBI_API_KEY="0123...ef"
  ```

设好后，技能会自动使用它，你无需再手动提供。

## 五、常见问题

- **Key 会过期吗？** 一般不会自动过期，但你随时可以在设置页 **Delete** 后重新生成一个。
- **Key 能给别人吗？** 不能。它绑定你的账户，相当于密码，别外传。
- **邮箱填了干嘛？** NCBI 建议填，方便他们在接口出问题时联系你，纯属礼貌字段，不强制。
- **还是看不懂？** 直接把报错或卡住的地方发给我，我一步步带你点。
